# S&H Spa Massage — Bespoke Website Concept

An editorial website and booking enquiry experience created for **S&H Spa Massage** at **429 Montrose Avenue, Toronto, ON M6G 3H2, Canada**.

## Overview

- **Creative Direction**: Inspired by quiet luxury and editorial warmth, using the actual interior photographs of S&H Spa Massage's treatment suites.
- **Typography**: `Cormorant Garamond` paired with `Plus Jakarta Sans`.
- **Booking Enquiry**: Interactive reservation request builder with date validation and direct forwarding via email (`mailto:`), SMS (`sms:`), clipboard copy, or telephone.
- **GitHub Pages Ready**: Configured with `.github/workflows/deploy.yml` for automatic deployment to `https://jayendrasinh025.github.io/S-H-SPA/`.

## Local Development

```bash
npm install
npm run dev
```

## Production Build
